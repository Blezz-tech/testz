# Методика художественного перевода 《剑来》

Практическое руководство по переводу романа Фэнхо Си Чжухоу **《剑来》** («Грядущий меч») на русский язык. Документ описывает **решения**, а не общие рассуждения о переводе: каждый пункт — правило, которое можно проверить в готовом тексте.

- [Рабочий процесс](TRANSLATION_WORKFLOW.md) — пошаговый пайплайн перевода главы.
- [Лор-Вики](../wiki/README.md) — карточки с каноническими именами и правилами.
- [Полный указатель вики](../wiki/INDEX.md) — все статьи.

---

## 1. Что это за текст и почему он сложен

| Свойство | Следствие для переводчика |
| :--- | :--- |
| **1198 глав**, из них половина — диалоги и притчи | Нельзя держать в голове канон: он живёт в `wiki/` |
| Сюжет движется **разговорами**, а не событиями | Реплика важнее описания; ритм диалога — главное |
| Автор любит **недоговорку**: смысл раскрывается через 200 глав | Не объяснять в тексте то, что автор не объяснил |
| Постоянные **отсылки к Трём учениям** | Философский словарь должен быть единым от первой до последней главы |
| Много **«говорящих» имён** и каламбуров | Имена — не украшение, а часть сюжета |
| Автор **сам иронизирует** над пафосом | Не переводить иронию в патетику |

Главная ошибка переводчика 《剑来》 — **сделать текст умнее, чем он есть**. Роман написан просто и намеренно: сложность в подтексте, а не в лексике. Если абзац в переводе звучит «литературнее» оригинала — это ошибка.

## 2. Имена и обращения

### 2.1. Люди: система Палладия

Основа — **транскрипция по Палладию**, без пиньиня и без англицизмов.

| Китайский | Правильно | Неправильно |
| :--- | :--- | :--- |
| `陈平安` | Чэнь Пинъань | Чэнь Пингань, Chen Ping'an, Чэнь Пин Ань |
| `宁姚` | Нин Яо | Нин Яо (без изменений) |
| `齐静春` | Ци Цзинчунь | Ци Цзинчун |
| `阮邛` | Жуань Цюн | Жуань Цюн |
| `崔瀺` | Цуй Чань | Цуй Чань |
| `阿良` | А-Лян | А Лян, Алян |

**Склонение.** Китайские имена на согласный склоняются как обычные существительные: *Чэнь Пинъаня, Нин Яо (не скл.), Цуй Чаня*. Если имя оканчивается на `-о`, `-э`, `-и`, `-у` — не склоняется. Правило фиксируется в карточке персонажа полем «Склонение».

**Исключения.** Если строгий Палладий даёт в русском непристойное или комичное созвучие, допускается фонетическая правка, но она **фиксируется в карточке** и соблюдается до конца романа. Молчаливые исключения запрещены: читатель заметит разнобой через сто глав.

### 2.2. Топонимы и организации: смысловой перевод

Названия мест, переулков, гор, сект и артефактов переводятся **по смыслу**, а не транслитерируются.

| Китайский | Перевод | Почему |
| :--- | :--- | :--- |
| `泥瓶巷` | Переулок Глиняных Кувшинов | Топография — часть сюжета |
| `骑龙巷` | Переулок Оседлавшего Дракона | Образ работает и в переводе |
| `落魄山` | Гора Лопо *(= «Гора Уныния»)* | Название — самоирония героя, в сноске |
| `剑气长城` | Великая стена мечевой ци | Термин, а не поэзия |
| `骊珠洞天` | Грот-небеса Личжу | Транслитерация + пояснение «грот-небеса» |

**Правило выбора.** Если образ названия понятен русскому читателю и работает в сюжете — переводить по смыслу. Если название — калька с чужого языка, набор редких иероглифов или культурная отсылка, требующая сноски, — транслитерировать и объяснять один раз.

Подробнее — [Правила создания карточек локаций](../wiki/locations/README.md) и [справочник сект](../wiki/factions/sects-compendium.md).

### 2.3. Обращения (称谓)

Обращение в 《剑来》 — маркер социальной дистанции. Переводить его надо **системно**, а не по наитию.

| Китайский | Перевод | Комментарий |
| :--- | :--- | :--- |
| `师父` | учитель / наставник | В ремесленной среде (гончары, кузнецы) — **мастер** |
| `先生` | господин / учитель | Для конфуцианских учёных сохранять оттенок наставничества |
| `师兄` `师姐` `师弟` `师妹` | старший брат / старшая сестра… (по школе) | В речи сокращается до *«старший брат Лю»*, когда контекст ясен |
| `小师叔` | младший дядька-наставник | Титул [Чэнь Пинъаня](../wiki/characters/chen-pingan.md); **сноска при первом появлении** |
| `道友` | собрат по Дао | Не «друг по Дао» |
| `前辈` | старший | Не «предшественник» |
| `姑娘` | барышня / госпожа | В устах простолюдина — просто *«девушка»* |
| `老祖` | патриарх / предок | Для глав родов и сект |

**Запрещено:** «господин Чэнь» там, где в китайском `陈小子` (парень Чэнь); «уважаемый» как универсальная заглушка.

## 3. Регистр «ты / вы» и голоса персонажей

Китайское `你` нейтрально, вежливость передаётся титулами. В русском приходится выбирать местоимение — и этот выбор должен быть **одинаковым во всех главах**.

### 3.1. Матрица

Для каждой пары говорящих в карточке персонажа есть таблица: кто кому «ты», кто кому «вы», и в каком контексте регистр меняется. Пример для [Чэнь Пинъаня](../wiki/characters/chen-pingan.md):

| Собеседник | Он → собеседнику | Собеседник → он | Контекст |
| :--- | :--- | :--- | :--- |
| [Нин Яо](../wiki/characters/ning-yao.md) | ты | ты | Ровесники, равные |
| [Старик Яо](../wiki/characters/old-man-yao.md) | вы | ты | Подмастерье и мастер |
| [Ци Цзинчунь](../wiki/characters/qi-jingchun.md) | вы | ты | Ученик и наставник |
| [Сун Цзисинь](../wiki/characters/song-jixin.md) | ты | ты | Соседи-ровесники, холодно |

**Правило смены регистра.** Если персонаж переходит с «вы» на «ты» — это **событие**, и оно должно быть заметно. Если случайно — это ошибка, которую поймает редактор.

### 3.2. Голоса

Каждый герой имеет узнаваемую манеру. В карточке есть раздел «Характер речи»:

- [Чэнь Пинъань](../wiki/characters/chen-pingan.md) — сдержанно, «счётно»: он всё время прикидывает цену, расстояние, остаток монет.
- [А-Лян](../wiki/characters/aliang.md) — легко, с шуткой, на «ты» со всеми, включая святых.
- [Цуй Чань](../wiki/characters/cui-chan.md) — книжно, витиевато, с удовольствием от собственной хитрости.
- [Пэй Цянь](../wiki/characters/pei-qian.md) — детская прямота, переходящая в деловитость.

Если реплику можно без потерь отдать другому персонажу — голос не найден.

## 4. Терминология: культивация и философия

Термины — самая частая причина «расхождения канонов». Всё, что относится к системе мира, берётся **только** из вики.

### 4.1. Ступени

- `境` — всегда **ступень**, никогда «уровень», «ранг», «тир», «сфера».
- Культиваторы ци: Грот → Созерцание моря → Врата Дракона → Золотое ядро → Зарождающаяся душа → Неогранённый нефрит → Бессмертный → Вознесение.
- Мастера боевых искусств: числительные + образное имя (*седьмая ступень — Алмазное тело*).

Полные таблицы с иероглифами и запрещёнными кальками: [Иерархия ступеней](../wiki/cultivation/realms-overview.md), [Путь культиваторов ци](../wiki/cultivation/qi-refinement.md), [Путь меча](../wiki/cultivation/sword-cultivator.md), [Боевые искусства](../wiki/cultivation/martial-arts.md).

### 4.2. Философский словарь

| Китайский | Канон | Не переводить как |
| :--- | :--- | :--- |
| `道理` | правда / резон / принцип | «Дао-принцип», «логика» |
| `本心` | изначальное сердце | «изначальный ум» |
| `规矩` | устои / правила | «регламент» |
| `气运` | судьбоносная удача | «аура удачи» |
| `心相` | образ сердца | «ментальный образ» |
| `功德` | заслуги | «карма» (это буддийский термин, у автора — конфуцианский счёт) |
| `香火` | благовония веры | «ладан» |

Полный словарь: [Даоли и бэньсинь](../wiki/idioms/daoli-and-benxin.md), [Судьбоносная удача](../wiki/concepts/qiyun.md), [Три учения](../wiki/cultivation/three-teachings.md).

### 4.3. Деньги и меры

`金精铜钱`, `神仙钱` — не «золотые монеты», а **деньги бессмертных** с курсом 1 : 100 : 10 000. См. [Денежная система](../wiki/concepts/currency.md). Меры (`ли`, `чжан`, `чи`, `цунь`) сохраняются, но при первом появлении — короткое пояснение в сноске; если точное число не важно, допустим смысловой перевод (`一刻钟` → «четверть часа»).

## 5. Сноски: фильтр трёх вопросов

Сноска — не способ объяснить всё непонятное, а инструмент сохранения второго смысла.

### Когда сноска обязательна

1. **Игра слов или двойное дно**, важное для сюжета или характера.
2. **Культурная, календарная, историческая или каноническая отсылка**, без которой непонятно, *почему* сцена устроена именно так.
3. **Яркий образ идиомы**, который при замене на нейтральный оборот теряет колорит.

### Когда сноска запрещена

- Обычные бытовые чэнъюй: `家徒四壁`, `孤苦伶仃`, `榆木疙瘩` — переводятся живыми русскими соответствиями (*«хоть шаром покати»*, *«круглый сирота»*, *«дубовая башка»*) **без сносок**.
- Всё, что читатель поймёт из контекста через абзац.
- Личные шутки переводчика и рассуждения о трудностях перевода.

### Типы устойчивых выражений

| Тип | Пример | В тексте | Сноска |
| :--- | :--- | :--- | :--- |
| Чэнъюй `成语` | `泥菩萨过江` | Перевод по образу: *«глиняный бодхисаттва на переправе»* | Если вторая половина оборвана автором — да |
| Сехоуюй `歇后语` | `泥菩萨过江——自身难保` | Сохранять образ целиком | Обычно нет: смысл прозрачен |
| Обряд, календарь | `二月二，龙抬头`, `惊蛰` | Художественно, ритмично | **Да, обязательно** |
| Скрытая цитата | `世间好物不坚牢，彩云易散琉璃脆` | Поэтически | **Да**, с указанием авторства |

### Оформление

```markdown
---
### Примечания

[^1]: **惊蛰 (Цзинчжэ)** — «Пробуждение насекомых», третий сезон солнечного календаря. В этот день весна окончательно вступает в силу.
```

**Нормы:**

- **1–6 сносок на главу.** Ноль — нормально, если глава простая. Десять — признак того, что переводчик боится текста.
- Формула: **термин → буквальный образ → смысл**. Три предложения максимум.
- Сноска **никогда** не раскрывает то, что автор раскроет позже. Анти-спойлерный фильтр действует и в примечаниях.
- Внутри абзаца никаких `[Прим. пер.: …]` — только надстрочный индекс.

## 6. Синтаксис и ритм

### 6.1. Длинные цепочки

Китайский период Фэнхо Си Чжухоу — 6–10 строк через запятую со скрытым подлежащим. При пословном переносе получается канцелярит.

**Правило:** разбивать на 2–4 русских предложения, восстанавливая подлежащее (*Чэнь Пинъань, юноша, подмастерье*), но **не добавляя** логических связок, которых нет в оригинале. Автор намеренно не говорит «потому что» — не надо говорить за него.

### 6.2. Ударный ритм

В кульминациях автор рубит фразу короткими конструкциями:

> `我陈平安，唯有一剑，可搬山，倒海，降妖，镇魔，敕神，摘星，断江，摧城，开天！`

Девять глагольных ударов должны остаться девятью:

> *«У меня, Чэнь Пинъаня, есть лишь один меч — но им я сдвину горы, опрокину моря, усмирю нечисть, подавлю демонов, повелю божествам, сорву звёзды, рассеку реки, сокрушу твердыни и разверзну небеса!»*

Если в переводе получилось восемь ударов или двенадцать — ритм потерян.

### 6.3. Поэзия и приговорки

- Народные присказки (`二月二，烛照梁，桃打墙…`) — ритмизованно, с фольклорной интонацией, без «псевдонародного» стиля.
- Классические стихи — белый стих с чётким метром или строгая рифма **без искажения образов**. Рифма не стоит ни одного образа.
- Стихи не переводятся прозой «для смысла»: если строка непонятна, объясняется в сноске, а не в тексте.

## 7. Что нельзя делать

### Русификация

| Нельзя | Почему |
| :--- | :--- |
| «попы», «молельня», «бесы лукавые» | Церковнославянский лексикон ломает мир |
| «аршины», «вершки», «гроши» | Русские меры и деньги |
| «богатырь», «витязь», «дума» | Русский эпос вместо китайского |
| Современный сленг («короче», «в натуре», «бесит») | Разрушает дистанцию |

### Калькирование

| Нельзя | Надо |
| :--- | :--- |
| «обнял кулак» (`抱拳`) | сложил ладони у груди в приветствии |
| «церковь даосов» (`道观`) | даосская обитель, храм |
| «друг по Дао» (`道友`) | собрат по Дао |
| «часовня предков» (`祠堂`) | родовой храм, зал предков |
| «золотая пилюля» (`金丹`) | Золотое ядро |
| «первозданный младенец» (`元婴`) | Зарождающаяся душа |

### Перевод через английский

Английские кальки дают двойной сдвиг: `grotto-heaven` → «пещерное небо» вместо **грот-небеса**, `sword immortal` → «мечевой бессмертный» вместо **бессмертный меча**. Переводить только с китайского.

### Ложные друзья

- `谢谢` — «спасибо», но в романе это и **имя** (Се Се).
- `天真` — «небесная истина» и «наивность»; меч [Нин Яо](../wiki/artifacts/heavenly-truths-swords.md) требует сноски.
- `先生` — не «мистер», а учитель.
- `小人` — не «маленький человек», а «ничтожный я» (самоуничижение).
- `东西` — «вещь», но в устах старшего — «создание, созданьице».

## 8. Чек-лист главы

Перед сдачей главы:

- [ ] Все имена сверены с карточками `wiki/`; новых нет или они заведены.
- [ ] Ступени и термины — по вики, без синонимов «для красоты».
- [ ] Регистр «ты / вы» соответствует матрице; смены регистра осознанны.
- [ ] Голоса персонажей различимы при чтении вслух.
- [ ] Сносок 1–6, каждая прошла фильтр трёх вопросов.
- [ ] Ни одна сноска не спойлерит будущие главы.
- [ ] Нет русизмов, калек и англицизмов.
- [ ] Длинные китайские периоды разбиты, лишних логических связок не добавлено.
- [ ] Ритм кульминаций сохранён (число «ударов» совпадает).
- [ ] Если в главе появилась новая сущность — карточка создана **до** сдачи перевода.
- [ ] `python3 scripts/wiki_tool.py check` проходит без ошибок.
