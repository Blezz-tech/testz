# 《剑来》 — русский перевод и Лор-Вики

Репозиторий проекта перевода романа **Фэнхо Си Чжухоу 《剑来》** («Грядущий меч») на русский язык.

Внутри три вещи, которые работают вместе:

- **`chapters/`** — полный китайский оригинал: 1199 файлов, 12,1 млн знаков, разбитый по главам и очищенный от мусора парсеров.
- **`wiki/`** — Лор-Вики на **195 карточек**: персонажи, локации, фракции, культивация, концепции, артефакты, идиомы, медиа. С китайским оригиналом, пиньинем, Палладием, первой главой появления и явными «Правилами перевода».
- **`docs/`** — методика и рабочий процесс: как переводить, какие сноски ставить, как не потерять канон на 1198 главах.

---

## Быстрый старт

```bash
# проверить целостность вики (YAML, типы, ссылки, дубли)
python3 scripts/wiki_tool.py check

# досье сущностей главы перед переводом
python3 scripts/wiki_tool.py scan chapters/0001.txt --max-chapter 1

# найти сущность по китайскому или русскому имени
python3 scripts/wiki_tool.py lookup 落魄山
```

Зависимостей нет: только Python 3.10+ и стандартная библиотека.

## Как устроена карточка

```yaml
---
id: char.chen-pingan
type: character
zh: 陈平安
zh_aliases: ["平安", "陈公子", "隐官"]
pinyin: Chen Ping'an
palladius: Чэнь Пинъань
ru: Чэнь Пинъань
first_chapter: 1
needs_endnote: true
---
```

Машиночитаемый заголовок + текст с перекрёстными Markdown-ссылками. Из заголовков собирается `wiki/_index.json`, по которому `scan` находит сущности в китайской главе за миллисекунды — и отсекает те, что появляются позже переводимой главы (**анти-спойлерный фильтр** по полю `first_chapter`).

Подробная схема полей — [wiki/README.md](wiki/README.md).

## Принципы проекта

1. **Канон живёт в вики, а не в голове.** Спорное имя, титул или термин сначала попадает в карточку, потом в перевод.
2. **Никаких спойлеров.** Всё, что относится к главам после текущей, скрыто под `<details>` с номером главы; `scan` фильтрует карточки по `first_chapter`.
3. **Смысловой перевод топонимов, Палладий для людей.** «Переулок Глиняных Кувшинов», но «Чэнь Пинъань».
4. **Сноска — инструмент, а не костыль.** 1–6 на главу, каждая проходит фильтр трёх вопросов.
5. **Ни одной внешней картинки.** Вики текстовая целиком.

## Лицензии и права

Китайский оригинал принадлежит **Фэнхо Си Чжухоу** и правообладателям. Тексты в `chapters/` размещены исключительно для переводческой работы. Карточки вики и документы в `docs/` — результат работы участников проекта.
