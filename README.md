# Проект перевода новеллы 《剑来》 («Грядущий меч»)

Репозиторий содержит полный китайский оригинал романа Фэнхо Сичжухоу **《剑来》 (*Jian Lai*)**, разбитый по главам, методическую базу художественного перевода и расширяемую **Лор-Вики (`wiki/`)** с перекрёстными ссылками.

---

## Структура репозитория

| Путь | Назначение |
| :--- | :--- |
| [`docs/TRANSLATION_BEST_PRACTICES.md`](docs/TRANSLATION_BEST_PRACTICES.md) | **Лучшие практики перевода** китайских веб-новелл (сянься/уся): работа со сносками к идиомам, система Палладия, «говорящие» имена и топонимы, уровни культивации, ритм и синтаксис. |
| [`docs/TRANSLATION_WORKFLOW.md`](docs/TRANSLATION_WORKFLOW.md) | **Рабочий регламент (пайплайн) агента-переводчика**: пошаговый порядок перевода каждой главы с проверкой по вики, двухпроходной редактурой и автообновлением базы знаний. |
| [`chapters/`](chapters/README.md) | Разбитый по главам и очищенный от встроенных водяных знаков текст романа (`0000_synopsis.txt`, `0000.txt` … `1197.txt`) + полный реестр [`chapters/index.json`](chapters/index.json). |
| [`wiki/`](wiki/README.md) | **Лор-Вики в стиле Fandom / Obsidian** с перекрёстными Markdown-ссылками, защитой от спойлеров по главам, матрицей «ты/вы» и автособираемым индексом [`wiki/_index.json`](wiki/_index.json). |
| `scripts/split_chapters.py` | Скрипт воспроизводимой разбивки исходного файла `剑来_全集_1198章.txt` на главы и генерации `chapters/index.json`. |
| `scripts/wiki_tool.py` | CLI-инструмент сборки индекса вики (`build`), валидации перекрёстных ссылок (`check`) и предпереводческого сканирования китайских глав (`scan`). |
| `剑来_全集_1198章.txt` | Исходный неразбитый архив текста (1198 записей с `51shucheng.net`). |

---

## Быстрый старт с инструментами

```bash
# Проверить целостность всех карточек и перекрёстных ссылок в Лор-Вики
python3 scripts/wiki_tool.py check

# Получить готовое предпереводческое досье по любой главе (например, Главе 1)
python3 scripts/wiki_tool.py scan chapters/0001.txt --max-chapter 1
```
