# Переводческие словари вики

Два русскоязычных справочника помогают сохранять единые формы перевода по всему роману.

## 1. Китайские идиомы и устойчивые выражения

[Открыть `chinese_idioms.json`](chinese_idioms.json)

Словарь включает чэнъюи, поговорки, каламбуры, цитаты и культурно значимые формулы, найденные в корпусе либо необходимые для пояснения уже заведённых карточек. Запись содержит китайскую форму, пиньинь, русский смысл, буквальный образ, переводческую заметку и ссылку на карточку вики, если она есть.

Поле `corpus_matches` показывает буквальные совпадения в нумерованных файлах `chapters/0000.md`–`1197.md`: количество строковых вхождений, файлы и первое совпадение. Отдельный файл аннотации `0000_synopsis.md` в этот подсчёт не входит. Это **не** подсчёт идиоматического употребления: выражение могло быть употреблено буквально, иронически или как часть более длинной фразы; не все повторы вручную размечены. Перед переводом проверяйте контекст главы; не заменяйте китайский образ привычной русской пословицей автоматически.

## 2. Словарь всех карточек вики

[Открыть `all_wiki_objects.json`](all_wiki_objects.json)

Содержит все карточки из `wiki/_index.json`: персонажей, локации, фракции, ступени и учения, концепции, артефакты, идиомы и медиа. Для каждой записи указаны каноническая русская форма, оригинал и китайские варианты, пиньинь, транскрипция Палладия, номер первого появления, тип, пол/подтип, переводческая норма, граф ссылок и путь к карточке. `translation_rule` объединяет подходящие разделы карточки (включая заголовки с «правилом», переводческим решением или эталонной формой); пустое поле означает, что такого раздела нет. `first_chapter: 0` указывает на вводный источник или справочную сущность без единой сцены-дебюта, а не на главу романа. Варианты, которые намеренно не участвуют в автоматическом поиске из-за неоднозначности, вынесены в `unindexed_zh_aliases`.

Этот файл автоматически пересобирается командой:

```bash
python3 scripts/wiki_tool.py build
```

Не правьте `all_wiki_objects.json` вручную: меняйте карточку, затем выполните `python3 scripts/wiki_tool.py check`.

## Общее правило

Если словарная запись и подробная карточка кажутся противоречивыми, приоритет у карточки и контекста романа. Поле `first_chapter` относится к первому появлению сущности; точное первое вхождение строки может быть раньше, если это другое лицо, омоним или обычное слово.
