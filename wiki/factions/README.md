# Фракции, государства и секты (`wiki/factions/`)

Раздел хранит карточки государств, конфуцианских академий (`书院`), даосских и буддийских школ, горных сект и кланов.

## Правила создания карточек
- Использовать шаблон [`../_templates/general_entity.md`](../_templates/general_entity.md) с полем `type: faction`.
- Названия династий передавать транскрипцией по Палладию с сохранением величительного префикса (`大骊` → **Великая Ли**, `大隋` → **Великая Суй**).
- Названия горных сект, академий и орденов переводить по смыслу (при необходимости с транскрипцией топонима).
