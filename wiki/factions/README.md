## Правила создания карточек

- Шаблон: [`../_templates/general_entity.md`](../_templates/general_entity.md), `type: faction`.
- `subtype` обязателен: `empire`, `nation`, `sect`, `academy`, `clan`.
- Названия династий — транскрипция с величительным префиксом: `大骊` → **Великая Ли**, `大隋` → **Великая Суй**.
- Названия сект — **по смыслу**: `风雷园` → Сад Ветра и Грома, `日晒山` → Гора Согревающего Солнца. Исключения (`太徽剑宗` → Тайхуэй) фиксируются в [сводке](sects-compendium.md).
- Каждая новая секта сначала попадает в [сводку](sects-compendium.md), потом в перевод.
