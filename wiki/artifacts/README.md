# Артефакты, мечи, книги и диковинки (`wiki/artifacts/`)

Раздел предназначен для хранения карточек именных мечей, летающих мечей (`飞剑` — см. [Культиватор меча](../cultivation/sword-cultivator.md)), сокровищ бессмертных (`法宝`), талисманов (`符箓`), редких монет и книг.

## Правила создания карточек
- Использовать шаблон [`../_templates/general_entity.md`](../_templates/general_entity.md) с полем `type: artifact`.
- Именные мечи и артефакты получают смысловой поэтический перевод (например, будущие мечи [Чэнь Пинъаня](../characters/chen-pingan.md) и других героев) с обязательной фиксацией китайского оригинала в `zh` для стопроцентного узнавания при повторных упоминаниях сотни глав спустя.
- Обязательно указывать текущего и прежних владельцев через перекрёстные ссылки на `../characters/*.md`.
