## Как устроена карточка персонажа

Каждая карточка содержит обязательные блоки:

1. **`## Правила перевода и речи`** — как передавать имя (склонение, Палладий, этимология), как говорит персонаж, как к нему обращаются.
2. **`## Отношения и регистр «ты / вы»`** — таблица из четырёх колонок. Это **не украшение**: если в переводе персонаж скажет «вы» там, где таблица требует «ты», это ошибка.
3. **`## Кто это`**, **`## Характер`** — описание **на момент первого появления**, без спойлеров.
4. **`## Хронология по главам (Spoiler-gated)`** — всё, что происходит позже, закрыто `<details>`-блоком с номером главы.
5. **`## Перекрёстные ссылки`** — минимум три связи.
