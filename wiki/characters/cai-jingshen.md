# Цай Цзиншэнь (`蔡京神`)

[← Портал Вики](../README.md) · [Полный указатель](../INDEX.md)

Прославленный по Великой Суй **практик ци десятого предела**; грузный старик из знатного столичного рода. Владыка Яньло для подопечных Цуй Чаня: пришёл «управлять» безумцем, когда Цуй Дуншань ругательствами вызвал его из усадьбы близ горы Дунхуа.

## Хронология по главам (Spoiler-gated)
- **Глава 167** — ночная дуэль с Цуй Чанем на вершине Дунхуа: молниеносные копья против летящего меча «Золотая осень» и сокровищ; по городу прозвали «прародителем рода Цай».
- **Главы 168–169** — Ли Эр обещает «прибрать» его по дороге обратно из дворца.
- **Глава 170** — развитие противостояния.
