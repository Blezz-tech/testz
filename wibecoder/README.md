# WIBECODER — техническая документация

> **Статус:** черновик v0.1 (design draft) · **Дата:** 2026-11-17
> **Жанр:** симулятор фриланс-разработчика с элементами тайкуна / idle-lite
> **Референс по духу и стилистике:** [Idle Streamer: Tuber](https://play.google.com/store/apps/details?id=com.wazzapps.idle.streamer) (эстетика, карточки, юмор, цикл «работа → награда → апгрейд»), **но механики — свои**.

---

## Питч в один абзац

Ты — бомж-разработчик в каморке. У тебя дешманская нейронка, которая генерирует говнокод и кривые картинки, и стопка счетов: еда, вода, ЖКХ, электричество, здоровье. К тебе летят **заказы** — от лендинга для шаурмичной до САПР для завода. Ты **выбираешь визуальные варианты** проектов, кормишь нейронку **токенами** (каждый токен — деньги), **правишь косяки**, сдаёшь — и получаешь копейки. За каждый проект растёт скилл **«как отпиздить нейронку, чтобы она делала вещи лучше»**. Копишь, арендуешь более дорогие нейронки, потом покупаешь железо и запускаешь модель локально (пока дешманскую — у видюхи не та VRAM), платишь за электричество, ловишь случайные ивенты (поранился, сгорел БП, заказчик-мудак) и постепенно поднимаешься от халтуры за копейки до серьёзных заказов с дедлайнами и жёсткими требованиями к качеству.

## Ключевые термины (выжимка)

| Терм | Определение |
| :--- | :--- |
| **Токены** | Расходный ресурс генерации. Тратятся при работе нейронки. Покупаются за деньги (API) или «бесплатны» на локальных моделях (но жрут электричество и время). |
| **Нейронка (модель)** | Инструмент генерации контента проекта. Тир от «Лампочки» (говно) до топовых API и локальных моделей на своём железе. |
| **«Как отпиздить нейронку»** | Главный скилл игрока (официальное название ветки — *Промтодрючение*). Повышает качество отдачи модели за каждый токен. |
| **Косяк** | Ошибка генерации (галлюцинация, кривой арт, баг в коде). Требует правки — времени, кликов или доп. токенов. |
| **Подсистема качества** | Одна из граней проекта: графика, геймплей/логика, музыка/звук, код, UX, оптимизация, документация. |
| **Халтура** | Заказ 1-го тира. Копейки, но еду заработать можно. |
| **Босс-заказ** | Сюжетный майлстоун-заказ с особыми условиями. |
| **VRAM** | Память видеокарты. Определяет, какую модель можно запустить локально. Отображается в UI постоянно. |

## Как пользоваться доками

- **Что делать в первую очередь:** прочитать 01–05 (петля игры и ключевые системы), затем 07 и 14 (экономика/баланс — тут живут канонические числа).
- **Числа:** все эталонные значения собраны в [14-balance.md](docs/14-balance.md). Остальные документы ссылаются на них и не дублируют.
- **Формулы** приведены в псевдокоде, пригодном для прямой реализации в C#/GDScript.
- Любой документ можно давать отдельному специалисту (геймдизайнеру, экономисту, аудио-дизайнеру, артисту, программисту).
