# 12. Арт и UI

## 12.1. Стилистика

По духу **Idle Streamer: Tuber** — яркий мультяшный 2D с «уютной комнатой»-хабом:

- Флэт+градиенты, жирные контуры, крупные формы, читаемо с маленького экрана.
- Персонаж — стилизованный «кодер в худи» (настраиваемый: цвет худи, причёска, тапки).
- Юмор в деталях: стопка немытых тарелок на старте → три монитора на L4; на стене — постер «НЕТ ДЕДЛАЙНАМ» (перевёрнутый вверх ногами).

### Палитра по уровням жизни

| Уровень | Палитра | Ощущение |
| :--- | :--- | :--- |
| L0 Каморка | Тусклые коричнево-серые + один яркий акцент (монитор) | «Подвал, но есть мечта» |
| L1 Комната | Теплее, +растение, +лампа | «Становится жить можно» |
| L2 Однушка | Светлые тона, чистота, первый игровой угол | «Стабильность» |
| L3 Студия | Яркие акценты, техника, LED-подсветка | «Круто» |
| L4 Студия мечты | Мультяшный «пентхаус-лаборатория» | «Ярко и нагло» |

## 12.3. Визуальные карточки заказов (главный UI-артефакт)

Требование из концепта: «нам даются варианты, причём визуально отображаемые». Карточка (см. мокап в [03](03-orders.md) §3.2) содержит:

1. **Превью-мокап** «ожидания заказчика» — уникальная иллюстрация на тип/тир (котик-пазл, лендинг шаурмы, чертёж САПР). Ключевой визуальный различитель.
2. **Иконку типа** (🎮/🌐/📱/⚙️) + цвет тира.
3. **Крупные числа**: 💰 оплата, ⏳ дедлайн, ⭐ репутация-порог.
4. **Полоски требований** (как на экране проекта, но усечённые).
5. **Одну строку флейвора** заказчика (юмор, см. [03](03-orders.md) §3.10).

Свайп влево — «пропустить», вправо — «взять» (мобильный паттерн) + кнопки для крупных экранов.

## 12.4. Экран генерации: визуал процесса

- **Лог нейронки** — «печатающийся» текст в стилизованном терминале (зелёный/синий моноширинный).
- **7 полосок подсистем** наполняются с анимацией; сегменты «косяков» — красные плашки поверх полоски.
- **Слайдеры токенов** — большие, «жирные», с калибровкой «сколько примерно даст» (число с ±10%).
- **VRAM-виджет** — постоянный, внизу экрана (см. [08](08-hardware.md) §8.3).
- У Лампочки-0.5 лог слегка «тупит» (курсор мигает, текст с опечатками); у топовых моделей — бегло и уверенно.

## 12.5. Анимации и VFX

| Момент | Анимация |
| :--- | :--- |
| Оплата заказа | «Дождь из купюр» + счётчик $ с перекатом цифр |
| Уровень жизни повышен | Комната «переезжает» — монтажная склейка с затемнением |
| Покупка GPU | Карта «вставляется» в системный блок с щелчком и вентиляторами |
| Косяк | Красная вспышка + дрожание полоски |
| «Золотой проект» | Золотые конфетти + радар-чарт «вспыхивает» |
| Троттлинг VRAM | Виджет краснеет, волна «тепла» по экрану |
| Выгорание | Экран слегка «плывёт», цвета притухают |

## 12.6. UI-кит и требования

- **Portrait-first** (мобилки), поддержка 16:9 / 19.5:9 / 20:9, safe-area.
- Минимальный тап-таргет 48×48 dp; основные кнопки — нижняя треть экрана (большой палец).
- Шрифты: заголовки — округлый «мультяшный» (например, Nunito/Baloo-класса), числа — табличный моноширинный, лог — моноширинный техно.
- Тёмная/светлая тема: тёмная по умолчанию («подвальный уют»), светлая — опционально.
- Локализация: RU/EN; все тексты в таблицах (см. [13](13-tech-architecture.md) §Localization).
- Цветовая слепота: статусы дублируются иконками и паттернами, не только цветом.

## 12.8. Референс-настроение (мудборд для артиста)

- «Уютный беспорядок»: провода, стаканы, стикеры на мониторе.
- Техника как персонаж: GPU с глазами в момент «сгорела», монитор «моргает».
- Контраст «серость быта vs яркость мечты»: чем дальше прогресс, тем ярче палитра и свет.
