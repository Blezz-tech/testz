# 02. Core Loop

## 2.1. Основной цикл (один заказ)

```
┌─────────────┐   ┌──────────────┐   ┌─────────────────┐   ┌──────────────┐
│ 1. Биржа:   │   │ 2. Планиро-  │   │ 3. Генерация:   │   │ 4. Правки:   │
│ выбрать     │──►│ вание:       │──►│ кормим нейронку │──►│ ловим косяки,│
│ визуальный  │   │ тип, бюджет  │   │ токенами по     │   │ чиним руками │
│ вариант     │   │ токенов,     │   │ подсистемам     │   │ или токенами │
│ заказа      │   │ дедлайн      │   │                 │   │              │
└─────────────┘   └──────────────┘   └─────────────────┘   └──────┬───────┘
                                                                   │
      ┌──────────────────┐   ┌──────────────────┐   ┌─────────────▼──────┐
      │ 7. Счета и жизнь:│   │ 6. Апгрейды:     │   │ 5. Сдача:          │
      │ еда, вода, ЖКХ,  │◄──│ токены, модель,  │◄──│ заказчик оценивает │
      │ электричество,   │   │ железо, скиллы   │   │ качество → оплата, │
      │ здоровье, ивенты │   │                  │   │ XP, репутация      │
      └──────────────────┘   └──────────────────┘   └────────────────────┘
```

Каждый виток занимает **2–8 минут активной игры** (в зависимости от тира заказа).

## 2.2. Минута за минутой: первый игровой день

| Время (реальное) | Что происходит |
| :--- | :--- |
| 0:00–0:30 | Туториал: комната, счётчик $50, счётчик токенов, полоска VRAM (серая — железа нет), счётчики еды/здоровья |
| 0:30–1:30 | Биржа: 3 карточки заказов (лендинг шаурмичной $30, пазл про котиков $45, сайт-визитка $35). Визуальный выбор |
| 1:30–3:00 | Генерация: распределяем стартовые токены (Лампочка-0.5 даёт мало и плохо), видим кривые результаты |
| 3:00–4:00 | Правки: 2–3 косяка, мини-игра починки |
| 4:00–4:30 | Сдача: заказчик недоволен, но платит копейки (≈$22). +XP |
| 4:30–5:00 | Счета: еда на день −$12, свет −$3. Баланс штормит |
| 5:00–6:00 | Покупка токенов на остаток, анонс «завтра придёт заказ получше» |

## 2.3. Мета-цикл (прогрессия)

| Уровень жизни | Доступно | Цель игрока |
| :--- | :--- | :--- |
| **L0. Каморка** | Халтура (тир 1), Лампочка-0.5, стартовые токены | Выжить, не съесть весь баланс |
| **L1. Съёмная комнат**а | Тир 2, аренда Шмодели/Среднячка, первый кредит | Выйти в плюс, поднять Промтодрючение |
| **L2. Однушка** | Тир 3, дорогие API, покупка GPU 4–8 ГБ | Освоить локальные модели, перестать зависеть от API-цен |
| **L3. Своя хата/студия** | Тир 4 и босс-заказы, GPU 16–24 ГБ, ферма | Закрывать корпоратив и САПР, набирать команду |
| **L4. Студия мечты** | Endgame: собственные продукты, пассивные доходы, «выход на биржу» | Косметика, достижения, нью-гейм+ |

## 2.4. Active vs Idle: честные правила

Игра **не обязательный idle**. Активные действия — ядро:

- **Выбор заказа** (визуальные карточки) — всегда активно.
- **Распределение токенов** по подсистемам — активно (слайдеры).
- **Правка косяков** — активно (мини-игры/выборы).
- **Реакция на ивенты** — активно (принять/проигнорировать/заплатить).

Что допустимо пассивно («idle-lite»):

| Пассивное действие | Условие | Что даёт |
| :--- | :--- | :--- |
| **Сон** (ночной тик) | Автоматически каждый игровой день | Восстановление здоровья и энергии, −еда |
| **Фоновая локальная генерация** | Игрок ушёл, модель загружена в VRAM | Медленный прирост качества подсистемы (×0.2 от активной скорости), жрёт электричество |
| **«Оставить проект на полке»** | Проект не сдан, дедлайн не горит | Ничего не происходит (проект не деградирует) — чтобы наказывать безделье только счетами, а не потерей прогресса |

Offline-прогресс (закрытая игра): считается максимум **8 игровых часов**, только фоновая генерация и «сон», все счета начисляются. Дольше — ничего (мотивация возвращаться, а не «открыл через неделю — миллиард»).

## 2.5. Петля напряжения: три «крана»

У игрока всегда три крана, и все тянут из кошелька:

1. **Токены** (качество проекта → доход).
2. **Жизнь** (еда/вода/ЖКХ/здоровье → без этого штрафы).
3. **Железо/модели** (долгосрочная эффективность).

Баланс построен так, что **всегда не хватает на всё**: на старте жизнь и токены съедают 90% дохода, к середине — аренда моделей и электричество, к концу — амортизация железа и налоги на студию.

## 2.6. Fail-состояния (не «game over», а «пинок»)

| Состояние | Условие | Последствие |
| :--- | :--- | :--- |
| **Выселение** | Баланс < 0 дольше 3 игровых дней | Мини-сцена «вещи в пакетах», сброс уровня жизни на ступень ниже, −репутация 10. Продолжаем |
| **Больница** | Здоровье = 0 | Принудительная «госпитализация» на 2 игровых дня, счёт за лечение $80, −энергия, проекты «пауза» |
| **Репутация в полу** | Репутация < 10 | Биржа показывает только мусор-заказы (тир 1 с ценой −30%), платные «курсы» перестают давать бонус |
| **Кредитная яма** | Долг > $500 | Коллекторские ивенты (см. [10](10-events.md)), −здоровье от стресса |

Важно: провалы **не обнуляют прогресс скиллов и моделей**. Игра наказывает кошелёк и статус, но не заставляет перепроходить всё заново.

## 2.7. Ритм сессии и дедлайны

- Дедлайн измеряется в **игровых днях** (см. тайминг в [13](13-tech-architecture.md), § GameClock).
- Последние 25% дедлайна — состояние «аврал»: музыка сменяется на тревожную, доступна кнопка **«Раш»** (ускорение генерации ×2, но −15% качества и −5 здоровья за игровой день).
- Просрочка не убивает заказ: заказчик принимает с коэффициентом оплаты (см. [05](05-quality.md)), но репутация падает.
