# 09. Характеристики персонажа

## 9.1. Статы (переменные состояния)

| Стат | Диапазон | База | На что влияет |
| :--- | :--- | :--- | :--- |
| **Здоровье** (Health) | 0–100 | 70 | Шанс ивентов-болезней, скорость правок, «больница» при 0 |
| **Энергия** (Energy) | 0–100 | 80 | Скорость активных действий (правки, переговоры) |
| **Настроение** (Mood) | 0–100 | 60 | `event_mult` к качеству, цены «по настроению заказчика» (репутация быстрее растёт при high mood) |
| **Стресс** (Stress) | 0–100 | 10 | Растёт от раша, дедлайнов, кредитов; >70 → качество −10%, шанс «выгорания» |
| **Репутация** (Rep) | 0–100 | 10 | Доступ к тирам заказов, множитель оплаты (см. [03](03-orders.md)) |

Статы показываются иконками в шапке (см. [12](12-art-ui.md)); тенденция (↑↓) — стрелкой за последние дни.

## 9.2. Как статы входят в формулы

```python
# event_mult — общий множитель качества (см. [04] §4.4):
event_mult = 1.0
event_mult *= (1 - 0.20 if energy < 30 else 1)        # усталость
event_mult *= (1 - 0.10 if stress > 70 else 1)        # стресс
event_mult *= (1 - 0.10 if health < 30 else 1)        # болезнь
event_mult *= (1 + 0.05 if mood > 70 else 1)          # кураж
event_mult *= (1 - 0.15 if rush_mode else 1)          # аврал (см. [02] §2.7)

# скорость ручных правок:
fix_time_sec = base_fix_time * (1 + 0.5 * (1 - energy/100)) * (1 - 0.15 * lvl_debug)
```

## 9.3. Изменение статов (типичные дельты)

| Действие / ситуация | Health | Energy | Mood | Stress |
| :--- | :--- | :--- | :--- | :--- |
| Полный рабочий день (3+ генерации) | — | −15 | −5 | +10 |
| Сон (ночной тик) | +8 | +40 | +5 | −10 |
| Хорошая еда | — | +5 | +5 | — |
| Дошик 3 дня подряд | −5 | −5 | −10 | +5 |
| Успешная сдача («золотой проект») | — | −5 | +15 | −15 |
| Провал заказа | −5 | — | −20 | +20 |
| Раш-режим 1 день | −5 | −25 | −10 | +25 |
| Прогулка/отдых ($10) | +5 | +10 | +10 | −15 |
| Кредит взят | — | — | −10 | +15 |
| Ивент «травма» | −10…−25 | −10 | −10 | +10 |

## 9.4. Пороговые состояния (дебаффы)

| Условие | Состояние | Эффект |
| :--- | :--- | :--- |
| Health < 30 | «Хроническая фигня» | `event_mult −10%`, +шанс ивентов-болезней ×2 |
| Health < 15 | «Загнулся» | −скорость всего ×20%, принудительное лечение если < 5 |
| Energy < 20 | «Выжатый лимон» | правки ×1.5 времени |
| Mood < 25 | «Мрак» | репутация растёт ×0.5, −шанс «хороших» ивентов |
| Stress > 70 | «На грани» | `event_mult −10%`, шанс «Выгорание» (ивент) 15%/день |
| Stress = 100 | «Выгорание» (принудит.) | 2 дня без работы, −Mood −30 |

## 9.5. Восстановление

| Способ | Стоимость | Эффект |
| :--- | :--- | :--- |
| Сон (авто) | еда за день | Health +8, Energy +40, Stress −10 |
| Отдых «гулять» | $10 + 2 часа | Mood +10, Stress −15 |
| Спортзал/пробежка | $5 + 2 часа | Health +5, Energy +10, Stress −10 |
| Таблетки/витамины | $5 (×2/день) | Health +5 |
| Врач | $40 | Снимает статус-заболевание |
| Отпуск (L2+) | $200–800 | Всё +20…+30, −стресс до 0 |
| Больница (Health=0) | $80 + 2 дня | Health → 50 |

## 9.6. Ночь и «утренний тик»

Каждый игровой день завершается ночным тиком:

1. Сон: восстановление (§9.5), −еда (2 приёма).
2. Счета: еда, вода, ЖКХ, электричество ([07](07-economy.md)).
3. Шанс ивента ([10](10-events.md), ~35%).
4. Обновление биржи, ротация цен токенов.

## 9.7. Видимость для игрока

- Шапка: 5 иконок с цветовой зоной (зелёная >60, жёлтая 30–60, красная <30).
- Экран «Жизнь»: крупные карточки статов с советами («Стресс 72 — сходи гулять, −15 за $10»).
- Всплывающие тосты при пересечении порогов: «⚠️ Энергия на нуле: правки стали медленнее».

## 9.8. Смерть/провал (полная)

Персонаж не умирает навсегда. Полная «смерть» = комбинация выселения + больницы + репутации в ноль:

- Сцена «Ты сидишь на чемодане. Ноутбук — единственное, что твоё».
- Ресет уровня жизни на L0, −50% денег, скиллы и модели сохраняются (см. [02](02-core-loop.md) §2.6).
- Достижение «Перезагрузка» + юмористическая запись в статистику.
