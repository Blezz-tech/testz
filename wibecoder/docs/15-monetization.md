# 15. Монетизация и метрики

## 15.1. Модель

**Free-to-play**, по духу Idle Streamer: Tuber: реклама + мягкие ИАП. Принцип: **никогда не продавать то, без чего нельзя пройти контент**. Деньги покупают комфорт и скорость, не победу.

## 15.2. Реклама

| Формат | Где | Механика |
| :--- | :--- | :--- |
| **Rewarded (по желанию)** | После сдачи заказа | «Удвоить гонорар за просмотр» (ограничение: 5 раз/день) |
| Rewarded | Магазин токенов | «Пригоршня токенов бесплатно за ролик» (1 раз/день) |
| Rewarded | Ивент | «Перегенерировать косяк бесплатно за просмотр» (альтернатива токенам) |
| **Баннер** | Между экранами (биржа, магазин) | Не во время активной генерации и мини-игр! |
| **Interstitial** | Каждые 3–4 сданных заказа | Пропуск через 5 сек, не чаще 1 раза в 15 минут |

Правила: **никакой рекламы в момент концентрации** (генерация, правки, выбор заказа). Реклама — «пауза между делами».

## 15.3. ИАП

| Товар | Цена | Содержание |
| :--- | :--- | :--- |
| **Убрать рекламу** | $4.99 | Навсегда; rewarded остаётся, но «за бонус» без роликов (×1.5 вместо ×2) |
| **Стартовый набор** | $2.99 | $500 + 50k токенов + косметический «кофе-кружка» |
| Пакет токенов «Пригоршня/Ведро/Бочка/Цистерна» | $0.99 / $3.99 / $11.99 / $39.99 | Как в [14](14-balance.md), но за реальные деньги (×1.2 к игровой цене) |
| **Кошелёк** | $4.99 | +$2k игровых |
| **Косметика** | $0.99–2.99 | Скины комнаты, худи, «золотая Лампочка-0.5», постеры |
| **Сезонный пропуск** | $4.99/мес | Косметика + «хроника ивентов» с бонусами XP (+10%), без силовых бонусов |

Запрещено: «снять дедлайн за деньги», «отменить ивент за $0.99», «открыть тир заказов донатом».

## 15.4. Где игрок «хочет» заплатить (органические точки)

1. Хочет закрыть босс-заказ, а токены кончились → пакет токенов.
2. Увидел карточку новой модели и «VRAM не хватает» → кошелёк на GPU.
3. Надоели баннеры → «убрать рекламу» (лучший конвертер).
4. Привязался к комнате/персонажу → косметика.

## 15.7. Баланс «донат vs прогресс»

- Пакет токенов ускоряет, но **не заменяет скилл**: без Promptsmithing и правок дорогие токены превращаются в качество с убывающей отдачей (см. [04](04-generation-ai.md) §4.4).
- Лимит rewarded-удвоений (5/день) не даёт «фармить рекламой» вместо игры.
- A/B: ценность «Стартового набора» проверяется на когортах (цель: +3% к D7 без падения органических покупок).

## 15.8. Юмор-подача в магазине

- «Убрать рекламу: потому что ты заслуживаешь смотреть на свою кривую графику, а не на чужую.»
- «Кошелёк: время = деньги. Тут просто деньги.»
