# 16. Глоссарий и roadmap

## 16.1. Глоссарий

| Терм | Определение |
| :--- | :--- |
| **Wibecoder** | Название игры (рабочее; эм-дизайн допускает ребрендинг до альфы) |
| **Токены** | Расходный ресурс генерации нейронки. Покупаются за $ (API) или «бесплатны» на локальных моделях (электричество/время) |
| **Qm** | Качество модели — потолок прироста качества за токен ([04](04-generation-ai.md)) |
| **need** | Базовая потребность подсистемы в токенах (с учётом тира и потребления модели) |
| **Q_total / Q_final** | Итоговое качество проекта до/после штрафа за косяки ([05](05-quality.md)) |
| **Подсистема** | Грань качества: графика, геймплей, музыка, код, UX, оптимизация, документация |
| **Промтодрючение** | Внутриигровое название главного скилла «как отпиздить нейронку» ([06](06-skills.md)) |
| **Косяк** | Ошибка генерации; правится руками (мини-игры), перегенерацией токенами или «оставить как есть» |
| **Халтура** | Заказ тира 1 |
| **Босс-заказ** | Сюжетный майлстоун-заказ, открывающий уровень жизни |
| **Золотой проект** | Сдача с `Q_final ≥ 1.15 × Q_required` и выполненными точечными требованиями |
| **Раш** | Режим аврала: ускорение ×2, штрафы к качеству и здоровью |
| **VRAM** | Память GPU; ограничивает класс локальной модели (постоянно видна в UI) |
| **H0/H1/H2** | Локальные модели («Гаражная/Домашняя/Фермерская») |
| **L0–L3 / P1–P2** | API-модели (дешёвые → топовые) |
| **L0–L4 (уровни жизни)** | Стадии: каморка → комната → однушка → студия → студия мечты |
| **Ночной тик** | Событие конца игрового дня: сон, счета, шанс ивента, обновление биржи |
| **Ивент** | Случайное событие, меняющее статы/переменные ([10](10-events.md)) |
| **Микрозайм «До аванса»** | Кредит с 20% за 3 дня — крючок отчаяния |
| **Флейвор** | Юмористический текст/визуал без влияния на механику |

## 16.2. Roadmap разработки

### Фаза 0. Прототип (3–4 недели)

- [ ] Core loop «заказ → токены → качество → оплата» на серых квадратах
- [ ] Формулы качества/оплаты + юнит-тесты ([04](04-generation-ai.md), [05](05-quality.md))
- [ ] 3 модели (L0, L2, H0), 5 заказов, без ивентов
- [ ] Симулятор баланса ([13](13-tech-architecture.md) §13.9) — прогнать траекторию [14](14-balance.md) §14.7

### Фаза 1. Альфа (8–10 недель)

- [ ] Все системы из доков 03–10 (заказы, генерация, качество, скиллы, экономика, железо, статы, ивенты)
- [ ] Экраны 1–8 ([12](12-art-ui.md)), серый + заготовленный арт
- [ ] Музыка M01–M05, SFX базовый набор
- [ ] Сейвы, GameClock, офлайн-расчёт
- [ ] Закрытый тест (100–300 чел.), метрики D1/прохождение туториала

### Фаза 2. Бета (6–8 недель)

- [ ] Полный арт и UI-кит, анимации §12.5
- [ ] Музыка полный трек-лист, адаптивные слои
- [ ] Босс-заказы и сюжетные ивент-цепочки
- [ ] Монетизация ([15](15-monetization.md)) + A/B
- [ ] Оптимизация под 60 FPS на референсных девайсах
- [ ] Локализация EN

### Фаза 3. Софт-лонч и релиз

- [ ] Софт-лонч (UA-тест, retention-цели §15.5)
- [ ] Итерации баланса по данным симулятора и когорт
- [ ] Глобальный релиз Android/iOS → порт на Steam
- [ ] Контент-патчи: новые типы заказов, «Сезонные ивенты», престиж

## 16.3. Открытые вопросы

1. **Имя**: «Wibecoder» — рабочее. Нужен ли более «мобильный» титул (напр., «Нейрофриланс: Халтура и Токены»)?
2. **Idle-глубина**: насколько сильно фоновая генерация должна быть выгодной? (Сейчас ×0.2 — обсудить с тестерами.)
3. **Полноценная «команда»** (нанимать помощников-нейрокодеров) — в контент-патч или в престиж?
4. **Мультиплеер**: «биржа заказов с другими игроками» (асинхронно) — по метрикам D30 решить, стоит ли.
5. **VR-режим/мини-игра «сборка ПК»** — сторителл-момент или отдельный режим?
6. Объём сюжетного «слоя» босс-заказов (сейчас 3–5 майлстоунов) — по тестам вовлечённости.

## 16.4. Источники вдохновения (честный список)

- **Idle Streamer: Tuber** — эстетика, карточки, ритм наград ([01](01-vision.md) §1.3).
- **Game Dev Tycoon** — цикл «проект → оценка → прогресс».
- **PC Building Simulator** — любовь к железу и VRAM-виджетам.
- **Papers, Please / This War of Mine** — быт, счета, «выбор без хорошего варианта».
- Реальная боль разработчиков: токеновые счета, дедлайны, заказчики-мудаки, сгоревшие БП.
