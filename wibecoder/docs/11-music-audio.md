# 11. Музыка и звук

## 11.1. Музыкальное направление

**«Уютный чиптюн-лоуфай про бомжа с мечтой»** — на стыке:

- **Чиптюн / бит-мейкерский лоуфай**: тёплые синты, мягкие драмы, «подвальный уют».
- **Синтвейв-лайт**: для моментов «работа кипит», «победа», «дорогие заказы» (когда игра «качает»).
- **Комедийные стингеры**: глитч-акценты для косяков нейронки, «тревожный ксилофон» для счетов.

Референсы по духу (не копировать, а отталкиваться): OST Tuber Simulator / Idle Streamer (ловкие петли, «жвачка», но с характером), Stardew Valley (уют), Hacknet («работа за компом»), Papers, Please (тревога быта).

## 11.2. Технические требования к музыке

| Параметр | Значение |
| :--- | :--- |
| Формат | OGG Vorbis (мобилки) / WAV мастер |
| BPM-диапазон | 90–120 (основное), 130+ для «аврала» |
| Лупы | Seamless loop, loop points в метаданных (или зацикленные 16/32-тактовые петли) |
| Длительность треков | 60–120 сек основные, стингеры 2–8 сек |
| Громкость | −14 LUFS интегральная, пик −1 dBTP |
| Стриминг память | ≤ 256 КБ/мин (мобилки), общая аудио-бюджет ≤ 30 МБ в билде |
| Динамика | Плавные переходы: crossfade 1.5–3 сек, ducking SFX −6 dB под музыку |

## 11.4. Адаптивность (слои)

Основные треки (M01–M03, M08) — **2–3 слоя**, которые добавляются/убираются по состоянию:

```
Слой 1 (база):   пэды/базовая линия — всегда
Слой 2 (ритм):   драмы — когда игрок активно работает (генерация идёт)
Слой 3 (акцент): мелодия/лид — при «золотом» прогрессе (качество > требований)
```

Переходы по триггерам:

| Триггер | Переход |
| :--- | :--- |
| Вход в экран генерации | M06/M01 → M02 (crossfade 2 сек) |
| Дедлайн < 25% | M02 → M03 (резкий стингер M09 посередине) |
| Сдача успешна | любой → M04 (стингер, поверх) |
| Ночной тик со счетами | любой → M05 |
| Stress > 70 | слой-дрон M13 поверх текущего |

## 11.6. Голос и логи

- Голоса как такового нет (бюджет/локализация), но **лог генерации** — «голос нейронки» (см. [04](04-generation-ai.md) §4.6) с типинг-звуком S02.
- Возможны «мысленные вздохи» персонажа (S10) как эмоциональные акценты.

## 11.7. Реализация

- Стандарт: **FMOD Studio** (слои, ducking, параметры «стресс/дедлайн») либо, на урезанном бюджете, Unity Audio + crossfade-контроллер с параметрами.
- Все лупы — `loop_start/loop_end` в импорте; стингеры — `one shot`.
- Настройки: 2 слайдера (Музыка / Эффекты), mute-тумблер; рингтон телефона (системный) — опционально.
