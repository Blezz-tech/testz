# 10. Случайные ивенты

## 10.1. Роль ивентов

Из концепта: «могут быть случайные ивенты с изменением характеристик и переменных — к здоровью, т.е. поранился». Ивенты — главный источник **непредсказуемости**: они меняют статы ([09](09-character-stats.md)), деньги, цены, железо, репутацию и условия заказов.

## 10.2. Менеджер ивентов

```python
# на ночном тике:
if rand() < base_chance:            # base_chance = 0.35, +0.15 если stress>70, +0.10 если health<30
    pool = events.filter(conditions_ok)      # условия: деньги, статы, железо, прогресс
    e = weighted_pick(pool, weights)
    e.apply()                                # меняет переменные немедленно или даёт выбор
    show_event_card(e)                       # визуальная карточка (см. [12])
```

- **Кулдаун**: один и тот же ивент не чаще 1 раза в 3 игровых дня.
- **Типы реакции**:
  - *Мгновенный* («поранился») — карточка-уведомление, эффект сразу.
  - *Выбор из 2–3 вариантов* («сгорел БП: купить новый / чинить самому / жить без ПК») — активная механика.
  - *Цепочка* («простуда → не лечился → грипп») — 2–3 стадии.

```python
weights = {

  "hardware":     1.5,     # E05–E07 — только с железом

```

## 10.5. Визуальная подача

- Ивент — **карточка поверх экрана** (как в референсе): иконка-мультяшка, заголовок, 1–2 строки юмора, кнопки выбора.
- Мгновенные ивенты — тост + иконка в ленту «хроники» (можно перечитать).
- Плохие ивенты: тревожный стингер ([11](11-music-audio.md)); хорошие — позитивный дзинь.

## 10.6. Что ивенты НЕ делают

- Не обнуляют прогресс скиллов/моделей.
- Не «выпадают» в момент активной мини-игры правки (ждут паузы).
- Не блокируют игру дольше 2 игровых дней (максимальный «простой»).
- Не требуют реальных денег как «решение» (никакого «заплати 99 центов, чтобы отменить ивент»).
