# 06. Прокачка и скиллы

## 6.1. Источник прогресса

Из концепта: «за создание проекта мы прокачиваем навык — как отпиздить нейронку, чтобы она лучше делала вещи». Скиллы растут от **опыта (XP)**, который капает за сданные заказы (и немного — за правки и ивенты).

```python
xp_needed(level) = 100 * level^1.5          # ур. 1→2: 100, 10→11: 3162
xp_gain = project_complexity * (Q_final / 50) * (1 + 0.1 * tier)
```

Уровень навыка = 0..20. Точки навыка: 1 за уровень, вкладываются в ветки (см. §6.3).

## 6.2. Главный скилл: «Как отпиздить нейронку» (Промтодрючение)

Системное название ветки — **Promptsmithing**, внутриигровое (и каноническое в команде) — **«как отпиздить нейронку»**. Это крепость всего прогресса:

| Уровень | Модификатор | Перк-майлстоун |
| :--- | :--- | :--- |
| 0–4 | `skill_mult = 1 + 0.06*lvl` | — |
| 5 | ×1.3 | **«Слышу подтекст»**: прогноз прироста показывает ±5% вместо ±10% |
| 10 | ×1.6 | **«Промпт-кнут»**: −20% к `error_rate` всех моделей |
| 15 | ×1.9 | **«Токен-экономия»**: `need` всех подсистем −10% |
| 20 | ×2.2 | **«Нейронка слушается»**: одна бесплатная перегенерация на проект |

Почему это важно экономически: `skill_mult` умножает прирост **до** убывающей отдачи, то есть высокий скилл делает эффективным каждый токен — тот же бюджет даёт больше качества. Это и есть «отпиздить нейронку, чтобы она лучше делала вещи».

## 6.3. Дерево навыков

Шесть веток, все прокачиваются точками уровня (или «курсами» — §6.5):

| Ветка | Эффект за уровень | Специализация |
| :--- | :--- | :--- |
| **Promptsmithing** («как отпиздить нейронку») | +6% `skill_mult` | Главная |
| **Специализация: Геймдев / Веб / Мобилки / САПР** | +3% к весу подсистем своего типа (перенормировка) +5% оплаты по типу | Выбирается 1 из 4 на ур. 3, вторая — на ур. 12 |
| **Правка/дебаг** | −4% `error_rate`, +15% скорость ручных правок | Косяки |
| **Переговоры** | +2% к оплате, −5% строгости дедлайнов | Деньги |
| **Железо/Администрирование** | −3% электричества локальных моделей, +5% скорость локальной генерации, −время загрузки модели в VRAM | Локальный инференс |
| **Выживание** | −4% расход еды, +10% восстановление здоровья | Жизнь |

Максимум по ветке — 10 уровней (кроме Promptsmithing — 20).

## 6.4. Модификаторы в формулах (сводка)

```python
skill_mult   = 1 + 0.06 * lvl_promptsmithing          # в прирост качества
error_rate  *= (1 - 0.04 * lvl_debug)                 # косяки
payout      *= (1 + 0.02 * lvl_negotiation)           # оплата
elec_cost   *= (1 - 0.03 * lvl_hardware)              # электричество
food_cost   *= (1 - 0.04 * lvl_survival)              # еда
type_bonus  = 1 + 0.05 * lvl_specialization[t]        # оплата по типу
```

## 6.5. «Курсы» и книги (доп. источник XP)

Сатира на инфоцыганство, но полезная механика:

| Предмет | Цена | Эффект |
| :--- | :--- | :--- |
| «Нейросети за 3 дня — стань миллионером» | $50 | +150 XP, −настроение 5 (игрок читает и охреневает) |
| «Промпт-инжиниринг PRO» | $300 | +800 XP в Promptsmithing |
| «Как выжить на фрилансе» | $120 | +300 XP в Выживание/Переговоры |
| Б/у книга с барахолки | $10 | +50 XP, 30% шанс «а это было про блокчейн» (ничего) |

Курсы покупаются за деньги, но **не заменяют работу**: XP за заказы — основной поток. Курсы — «добить уровень перед босс-заказом».

## 6.6. Репутация (не скилл, но рядом)

Описание в [03](03-orders.md) §3.8. Здесь важно: репутация — **второй столп прогресса** (скилл + репутация = доступ к тиру заказов). Растёт медленно (1–3 за заказ), падает быстро (−5..−10 за провалы) — «доверие нарабатывается годами, теряется за один дедлайн».

## 6.7. Престиж / Нью-гейм+

После L4 («Студия мечты») доступен **«Продать студию»** (престиж):

- Сброс: деньги, железо, уровень жизни.
- Сохраняется: 50% уровней скиллов, косметика, достижения, «инвестор» (стартовый капитал ×2 за каждую проданную студию).
- Награда: уникальные модели-скины («Лампочка-0.5 Gold»), титулы.

## 6.8. Что игрок реально делает руками (не «+5% в меню»)

| Механика | Как ощущается |
| :--- | :--- |
| Выбор модели и бюджета токенов | «Инженерное» решение каждые 5 минут |
| Правка косяков (мини-игры) | Активный скилл-чек |
| Переговоры о цене (1 выбор из 3 при приёме заказа) | Риск/награда |
| Раш/отдых перед дедлайном | Управление здоровьем |
| Прогноз прироста и «не докормил/перекормил» | Развитие чутья — и есть «промтодрючение» |
