# 07. Экономика и счета

## 7.1. Валюты и потоки

| Ресурс | Роль | Источник | Тратится на |
| :--- | :--- | :--- | :--- |
| **$** (деньги) | Основная валюта | Заказы, бонусы, находки | Еда, вода, ЖКХ, электричество, здоровье, токены, подписки, железо, кредиты |
| **Токены** | Расходник генерации | Покупка за $ (API); «время GPU» (локально) | Генерация качества |
| **XP** | Прогресс скиллов | Заказы, правки, курсы | Уровни и точки навыков |
| **Репутация** | Социальный капитал | Качественные сдачи | Доступ к тирам, цены |

```
        ЗАКАЗЫ ──► $ ──► [счета: еда/вода/ЖКХ/электричество/здоровье]
                    │
                    ├──► ТОКЕНЫ ──► ГЕНЕРАЦИЯ ──► качество ──► оплата заказа (↑)
                    │
                    └──► ЖЕЛЕЗО/МОДЕЛИ ──► меньше трат на токены, больше электричества
```

## 7.2. Расходы на жизнь (каждый игровой день)

Базовые значения — [14](14-balance.md). Сводка (день, L0 «каморка»):

| Статья | Сумма/день | Примечание |
| :--- | :--- | :--- |
| Еда | $12 | 3 уровня питания (см. §7.3) |
| Вода | $3 | Фикс |
| ЖКХ + интернет | $8 | Растёт с уровнем жизни (L1 ×1.5, L2 ×2.2, L3 ×3.5) |
| Электричество | $0.05/кВт·ч | Считается от железа (см. [08](08-hardware.md)); на старте ~$1–3/день |
| Здоровье | по факту | Лечение, таблы, больница |
| Токены | по факту | Главный переменный расход |
| Подписка на модель | по факту | Аренда API-тира (можно поставить на паузу) |

**Цель баланса**: на старте расходы ≈ 85–95% дохода («мы бомжи»), к средней игре — 60–70%, к концу — 40–50% (но и расходы абсолютные выросли в разы).

## 7.3. Еда и её влияние

| Уровень питания | Цена/день | Эффект |
| :--- | :--- | :--- |
| Дошик/сухпай | $7 | −настроение 5/день, −восстановление здоровья ×0.5 |
| Нормальная еда | $12 | Базово |
| Хорошая еда | $25 | +настроение 5/день, +энергия, +5% `event_mult` («сытый кодер думает лучше») |

Вода отдельно (фильтр/бутылки): без воды «дегидратация» — −энергия 10/день.

## 7.4. Электричество

Формула (детали в [08](08-hardware.md)):

```python
kWh_per_day = (gpu_tdp * gpu_hours + base_pc_load * 24) / 1000
elec_bill   = kWh_per_day * tariff * (1 - 0.03 * lvl_hardware)
```

- Тариф стартовый $0.05/кВт·ч, «перерасход» (если >150% нормы) → ×1.5 тариф («социальная норма» — сатира).
- Ивент «свет подорожал» — тариф ×1.3 на 3 дня (см. [10](10-events.md)).

## 7.5. Здоровье и деньги

- Таблетки/витамины: $5 → +5 здоровья (макс 2 раза в день).
- Приём врача: $40 → лечит статус-заболевание (простуда, спина).
- Больница (health = 0): $80 + 2 игровых дня простоя.
- «Полис» (покупаемая страховка, $20/неделю): лечение −50%. Сатира на медстрахование.

## 7.6. Кредиты (микрозаймы)

| Параметр | Значение |
| :--- | :--- |
| Доступ | Старт («Микрозайм “До аванса”»), до $500 |
| Ставка | 20% за 3 игровых дня (капитализация) |
| Просрочка | Ивенты «коллекторы» (−здоровье, −репутация, принудительное списание) |
| Банкротство | Долг > $1500 → «выселение» (см. [02](02-core-loop.md) §2.6) |

Кредит — главный «крючок отчаяния»: доступен всегда, но дорогой. Баланс таков, что кредит на токены под проценты часто выгоднее, чем безделье («взял $100, закрыл заказ за $300, отдал $120»), но 2 просрочки = яма.

## 7.7. Инфляция и ротация рынка

- Стоимость жизни +2% за игровую неделю (еда, ЖКХ).
- Цены токенов плавают ±10% от базы («биржа токенов» на UI: график-спарклайн как в брокерском приложении — визуальная шутка).
- Подписки на модели: провайдер «раз в 2 недели пересматривает условия» — ±15% цены.
- Смысл: **нельзя рассчитать стратегию на цифрах навсегда**; но разброс маленький, чтобы не бесить.

## 7.8. Точка безубыточности и цели баланса

| Метрика | Целевое значение |
| :--- | :--- |
| Первый заказ (тир 1, Q ~20) чистыми | $10–25 после счетов за день |
| Средний чек тира 2 к 3-му дню | $150–400 |
| Выход на стабильный плюс (доход > расход ×1.3) | День 4–6 |
| Окупаемость GPU ($150) | 8–12 игровых дней (если гонять локальную модель активно) |
| Переход на L2 «однушка» | ~день 8–10 |
| Босс-заказ №1 | ~день 12–15 |

(Полная прогрессия — [14](14-balance.md) §«Симуляция».)

## 7.9. Защита от «сломанной» экономики

- Анти-тупик: на бирже всегда есть заказ, покрывающий дневные расходы (§3.9 в [03](03-orders.md)).
- Анти-инфляция токенов: сгорание пакетов через 14 дней.
- Анти-хорды: кредит с жёсткими процентами, «выселение» как мягкий ресет кошелька.
- Анти-грайнд: убывающая отдача токенов и лимит активных проектов (1, см. [04](04-generation-ai.md) §4.10) не дают «фармить» бесконечно.

## 7.10. Экономический флейвор (цитаты)

- Счётчик в конце дня: «Еда −$12. Свет −$4. Нейронка сожрала $30. Ты в плюсе на $6. Это успех.»
- Микрозайм: «“До аванса” — аванса у тебя нет, но займ есть.»
- Биржа токенов: «📉 −3% — провайдер “оптимизировал стоимость”. 📈 +5% — провайдер “оптимизировал стоимость”.»
