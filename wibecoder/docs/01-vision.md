# 01. Видение и пиллары

## 1.1. Концепция

**Wibecoder** — симулятор жизни и работы фриланс-разработчика, который делает проекты для заказчиков с помощью нейронных сетей. Игрок начинает с дешманской моделью, генерящей мусор, и каморкой, за которую нечем платить. Каждый сданный проект — это ставка в казино из токенов, скилла и удачи: накормил нейронку токенами → поймал косяки → починил → сдал → получил копейки → заплатил за еду → купил ещё токенов.

Прогрессия — не «просто число растёт», а смена **инструмента и масштаба**:
халтура на дешманской нейронке → нормальные заказы на арендуемых моделях → топовые API → своё железо с локальной моделью → ферма GPU и серьёзные заказы с дедлайнами и ТЗ на качество.

## 1.2. Пиллары дизайна

1. **Нейронка — инструмент, а не автор.** Игрок управляет: сколько токенов влить, в какую подсистему, какую модель выбрать, править ли косяки руками. Результат — произведение игрока, а не «нажал кнопку и готово».
2. **Каждый токен на счету.** Токены — деньги. Дорогие модели жрут много токенов и стоят дорого за каждый. Главная напряжённая пара решений: «влить в качество или оставить на еду».
3. **Счета не дремлют.** Еда, вода, ЖКХ, электричество, здоровье — постоянный отток. Игра не даёт копить бесконечно: бездействие = минус на балансе. Отсюда — необходимость работать, а не «медленно расти само».
4. **Всё важное — визуально.** Варианты заказов, карточки моделей, полоска VRAM, дедлайны, качество подсистем — всё видно картинками и виджетами, без чтения простыней в момент выбора.
5. **Рост от каморки до студии.** Визуально и системно: комната, ПК, мониторы, потом своя студия. Каждый уровень жизни открывает новый класс заказов.

## 1.3. Референс: Idle Streamer: Tuber

Что **берём** из референса:

| Элемент | Как адаптируем |
| :--- | :--- |
| Яркий мультяшный 2D, «уютная комната» как хаб | Наш хаб — комната/студия разработчика, апгрейдится от каморки до офиса |
| Карточки апгрейдов и выборов | Карточки заказов, карточки моделей нейронок, карточки железа |
| Цикл «работа → награда → апгрейд» | «Проект → гонорар → токены/железо/еда» |
| Юмор, мемы, лёгкая сатира | Сатира на фриланс, заказчиков-мудаков, ИИ-хайп, курсы «как заработать на нейросетях» |
| Короткие сессии, понятный прогресс | Заказ 1-го тира закрывается за 2–5 минут активной игры |

Что **не берём** (и это осознанные отличия):

| Отличие | Почему |
| :--- | :--- |
| Idle-кликерность «батон, который пашет сам» | У нас **не обязательно idle**: основные решения активные (выбор заказа, распределение токенов, правки). Пассив — только «сон/отдых» и медленная локальная генерация на время отсутствия |
| Тема стриминга/ютуба | Тема — **разработка на нейронках**: заказы, токены, VRAM, качество проектов |
| Прогресс в основном через множители дохода | Прогресс через **смену инструмента** (модели, железо) и **скилл игрока** |
| Абстрактная «энергия кликов» | Конкретные ресурсы: токены, VRAM, кВт·ч, здоровье, еда |

## 1.4. Целевая аудитория

- **Ядро:** мобильные геймеры 16–35, фанаты тайкунов/симуляторов (Idle Streamer, Game Dev Tycoon, PC Building Simulator-аудитория).
- **Хук:** тема нейросетей — все слышали про ИИ, мало кто понимает, «сколько оно стоит в токенах». Игра даёт пощупать руками.
- **Вторичка:** разработчики (программисты/дизайнеры) — придут за сатирой и механикой «промтодрючения», останутся ради цифр, которые резонируют с реальной болью (счета за электричество, VRAM, дедлайны).
- Сессия: **3–10 минут**, 3–5 раз в день. Утренний «забрать заказы», обеденный «докрутить проект», вечерний «заплатить счета».

## 1.6. Тон, юмор, подача

- Ирония над фриланс-культурой: «заказчик: «сделайте как в ТЗ», ТЗ — одна строка», «микрозайм до аванса», «курс “Нейросети за 3 дня — стань миллионером”».
- Нейронка «говорит» в логах генерации: «Сгенерировано. *Возможно, это код.*», «Ошибка 42: не понял, что такое “котики”».
- Названия моделей — пародийные: **Лампочка-0.5**, **Шмодель**, **Среднячок**, **ТурбоПлюс-Про**, **Домашняя-7B** и т.д. (см. [04](04-generation-ai.md)).
- Мат и грубость — **во внутриигровых шутках и названиях скиллов** («как отпиздить нейронку» — официальное название ветки Промтодрючения), не в системных текстах.

## 1.7. Не-цели (чего игра не делает)

- Не симулирует реальные API реальных вендоров (все модели вымышленные).
- Не учит «настоящему программированию» (это не образовательный продукт).
- Не требует постоянного онлайн-подключения (офлайн-сейвы локальные).
- Не продаёт прогресс по подписке «чтобы играть» (см. [15](15-monetization.md)).
